1. Variabelen

In Python gebruik je een variabele om informatie te onthouden. Een variabele heeft een naam en een waarde. Je assigneert (geeft) een waarde aan een naam met het = teken. Denk aan een variabele als een doosje met een label erop waar je iets in stopt.

# Toewijzing (assignatie) van een variabele a met waarde 2
a = 2

# Toewijzing (assignatie) van een variabele woonplaats met waarde "Londerzeel"
woonplaats = "Londerzeel"

# Toon de waarde in een variabele
print(a)  # Op het scherm verschijnt: 2

Tip: Gebruik steeds duidelijke, korte namen voor variabelen.

2. Datatypes

Elke waarde in Python heeft een type. Dit bepaalt wat je ermee kunt doen (bijv. rekenen met getallen of knutselen met tekst). Denk aan een doos voor koeken en een doos voor boeken: allebei dozen maar gebouwd voor een verschillend doeleind.

# Integer (int): Gehele getallen
score = 10

# Float: Kommagetallen (gebruik een punt!)
prijs = 19.95

# String (str): Tekst, altijd tussen " " of ' '
naam = "Angela"

# List (list): Lijst, een verzameling van datatypes, altijd tussen []
hond = [4, "woef", "zacht"]

# Dicttionary (dict): Verzameling sleutels (vakken) met waarden (aantal lesuren), altijd tussen {}
rooster = {"Informatica": 1, "LO": 2}

# Boolean (bool): Waarheidsinstelling
is_gelukt = True
is_niet_gelukt = False

Tip: Een variabele zal automatisch herkennen welk type dit is. Verschillende types kan je niet zomaar combineren. Een variabele omzetten van het ene naar het andere type heet typecasting en doe je met int(variabele), str(variabele), ...

3. Vergelijken en logica

Met vergelijkingsoperatoren kan je controleren of waarden gelijk zijn of niet. Vergelijkingen of condities geven altijd een boolean terug.

a == b betekent: Is a gelijk aan b?

a != b betekent: Is a niet gelijk aan b?

x = 5

print(x == 5)  
# True

print(x == 3)  
# False 

print(x != 5)  
# False 

print(x != 3)  
# True 

print(x == '5')  
# False

Groter en kleiner

print(5 > 3)    # True
print(5 >= 5)   # True  (groter dan of gelijk aan)
print(2 < 1)    # False
print(2 <= 2)   # True  (kleiner dan of gelijk aan)

Let op: = kent een waarde toe, == vergelijkt.

Logische operatoren: and, or, not

leeftijd = 17

print(leeftijd >= 12 and leeftijd < 18)  # True  (beide waar)
print(leeftijd < 12 or leeftijd > 65)   # False (geen van beide waar)
print(not leeftijd == 17)              # False (draait de waarheid om)
print(12 <= leeftijd < 18)             # True  (korte schrijfwijze)

and is enkel True als alles waar is. or is True zodra minstens één voorwaarde waar is.

Zit het erin? De operator in

print("a" in "banaan")                  # True
print("rood" in ["rood", "blauw"])      # True
print("geel" not in ["rood", "blauw"])  # True

4. Keuzes: if, elif, else

Met if laat je code enkel uitvoeren als een conditie waar is. Met elif (anders als) en else (in alle andere gevallen) voeg je alternatieven toe. Python test van boven naar onder en voert enkel het eerste blok uit waarvan de conditie waar is.

punten = 14

if punten >= 16:
    print("Uitstekend")
elif punten >= 10:
    print("Geslaagd")
else:
    print("Niet geslaagd")

# Op het scherm verschijnt: Geslaagd

Belangrijk:

  • Na de conditie staat altijd een dubbelpunt :.
  • De inspringing/indentatie (4 spaties) bepaalt wat bij het blok hoort.
  • elif en else zijn optioneel. else heeft geen conditie.

Combineer condities met and en or, en plaats een if eventueel in een andere if:

n = 8

if n % 2 == 0 and n > 5:
    print("even en groter dan 5")

if n > 0:
    if n % 2 == 0:
        print("positief en even")

Tip: losse if-blokken worden allemaal getest. Bij if/elif wordt maar één blok uitgevoerd.

5. Rekenen met getallen

# + optellen   - aftrekken   * vermenigvuldigen   ** machtsverheffen
# /  gewone deling (geeft altijd een float)
# // gehele deling (afgerond naar beneden)
# % rest van de deling

print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1  (handig om te testen of een getal even is: n % 2 == 0)
print(2 ** 3)   # 8

print(round(3.14159, 2))  # 3.14
print(abs(-4), min(3, 8), max(3, 8))  # 4 3 8

import math # Zie H12: Modules en nette code
print(math.sqrt(16))  # 4.0

Tip: Python volgt de gewone volgorde van bewerkingen (machten, dan * en /, dan + en -). Gebruik haakjes als je twijfelt. Snelle schrijfwijze: x += 1 is hetzelfde als x = x + 1.

6. Rekenen met strings

Strings combineren en meten

voornaam = "Andreas"
achternaam = "Corthouts"

print(voornaam + " " + achternaam)  # Angela Peeters  (plakken)
print("ha" * 3)                        # hahaha  (herhalen)
print(len(voornaam))                    # 6  (aantal tekens)
print("go" in "Virgo")                  # True  (komt de tekst erin voor?)

Indexeren en slicing

Een string is een rij tekens en elk teken heeft een positie, beginnend bij 0. Met slicing haal je een stuk eruit: [start:stop:stap]. Het teken op start zit erbij, het teken op stop niet. Slicing werkt op strings én op lijsten.

woord = "Python"
#        P  y  t  h  o  n
# index: 0  1  2  3  4  5
# neg.: -6 -5 -4 -3 -2 -1

print(woord[0])      # P
print(woord[-1])     # n  (laatste teken)
print(woord[1:4])    # yth
print(woord[:2])     # Py  (begin weggelaten = vanaf het begin)
print(woord[3:])     # hon (einde weggelaten = tot het einde)

getallen = [10, 20, 30, 40, 50]
print(getallen[1:4])  # [20, 30, 40]

Let op: strings zijn onveranderlijk. woord[0] = "J" geeft een fout. Je maakt een nieuwe string, bv. nieuw_woord = "J" + woord[1:].

Handige string-methodes

tekst = "  Hallo Wereld  "

print(tekst.strip())               # "Hallo Wereld"  (spaties vooraan/achteraan weg)
print(tekst.upper())               #   HALLO WERELD
print(tekst.lower())               #   hallo wereld
print(tekst.replace("l", "L"))     #   HaLLo WereLd
print(tekst.find("W"))              # 8  (positie; -1 als het er niet in zit)
print(tekst.startswith("  H"))      # True

zin = "appel,peer,kiwi"
fruit = zin.split(",")             # ['appel', 'peer', 'kiwi']  (string wordt lijst)
print(" en ".join(fruit))           # appel en peer en kiwi  (lijst wordt string)

7. Lists

Een lijst gebruik je om meerdere variabelen in 1 datastructuur op te slaan. De volgorde van de variabelen is van belang. Je kan een element opvragen door de lijst te indexeren op een positie. De lijst begint steeds te tellen vanaf positie 0.

# Een lijst met drie strings:
kleuren = ["rood", "blauw", "groen"]

# Het eerste element opvragen (we tellen vanaf 0):
print(kleuren[0]) # Op het scherm verschijnt: rood

# Een rij opeenvolgende integers aanmaken (list() zet de range om naar een lijst)
print(list(range(2, 6))) # Op het scherm verschijnt: [2, 3, 4, 5]

Wijzigen, toevoegen en verwijderen

kleuren = ["rood", "blauw", "groen"]

kleuren[1] = "geel"         # element wijzigen
kleuren.append("paars")     # achteraan toevoegen
kleuren.insert(0, "zwart")   # op positie 0 invoegen
kleuren.remove("rood")     # eerste "rood" verwijderen
laatste = kleuren.pop()      # laatste element verwijderen en teruggeven

print(laatste)  # paars
print(kleuren)  # ['zwart', 'geel', 'groen']

Let op: append, insert, remove en sort veranderen de lijst zelf en geven niets terug. kleuren = kleuren.append("x") maakt van de lijst dus None.

Rekenen en sorteren

punten = [14, 9, 17, 12]

print(len(punten))               # 4  (aantal elementen)
print(sum(punten))               # 52
print(min(punten), max(punten))  # 9 17

print(sorted(punten))            # [9, 12, 14, 17]  (nieuwe lijst, origineel blijft)
punten.sort()                    # sorteert de lijst zelf
punten.sort(reverse=True)         # van groot naar klein: [17, 14, 12, 9]

Doorlopen met een index

for i in range(len(kleuren)):
    print(i, kleuren[i])

# 0 zwart
# 1 geel
# 2 groen

Heb je de index niet nodig? Gebruik dan gewoon for kleur in kleuren:.

Geneste lijsten (rooster of matrix)

Een lijst kan zelf lijsten bevatten. Met [rij][kolom] vraag je een element op.

rooster = [[1, 2, 3],
           [4, 5, 6],
           [7, 8, 9]]

print(rooster[1])      # [4, 5, 6]  (tweede rij)
print(rooster[1][2])   # 6  (rij 1, kolom 2)
rooster[0][0] = 10     # element wijzigen

for rij in rooster:
    for waarde in rij:
        print(waarde, end=" ")  # end=" ": blijf op dezelfde regel
    print()                    # nieuwe regel na elke rij

# 10 2 3
# 4 5 6
# 7 8 9

8. Dictionaries

Een dictionary gebruik je om meerdere variabelen in 1 datastructuur op te slaan. Elk element in de dictionary bestaat nu uit een sleutel (key) en een waarde (value). Het type van de waarden en de volgorde van de sleutel-waardeparen maken niet uit.

auto = {"merk": "Tesla", "jaar": 2023}

# Nieuwe sleutel/waarde toevoegen:
auto["kleur"] = "rood"
print(auto) # Output: {'merk': 'Tesla', 'jaar': 2023, 'kleur': 'rood'}

# Waarde opvragen via de sleutel:
print(auto["merk"]) # Output: Tesla

Wijzigen, verwijderen en opzoeken

auto = {"merk": "Tesla", "jaar": 2023}

auto["jaar"] = 2024       # waarde wijzigen
del auto["jaar"]          # sleutel met waarde verwijderen

print("merk" in auto)     # True  (in controleert de SLEUTELS)
print(len(auto))          # 1

Keys, values en doorlopen

auto = {"merk": "Tesla", "jaar": 2023}

print(list(auto.keys()))    # ['merk', 'jaar']
print(list(auto.values()))  # ['Tesla', 2023]

for sleutel in auto:               # doorloopt de sleutels
    print(sleutel, auto[sleutel])

for sleutel in auto.keys():               # doorloopt de sleutels ook
    print(sleutel, auto[sleutel])

for waarde in auto.values():  # doorloopt de waarden
    print(waarde)

9. De lus

For-loop met range(): gebruik je wanneer je iets een bepaald aantal keer wil herhalen. Python maakt automatisch een lijst van opeenvolgende getallen.

for i in range(0, 3):
    print("Herhaling", i)

# range(0,3) maakt de getallen: 0, 1, 2
# Output:
# Herhaling 0
# Herhaling 1
# Herhaling 2

For-loop met een lijst: gebruik je wanneer je door bestaande data wil gaan.

namen = ["Alice", "Bob", "Eve"]

for naam in namen:
    print("Hallo", naam)

# De nieuwe gedefinieerde variabele 'naam' wordt telkens een element uit de lijst
# Output:
# Hallo Alice
# Hallo Bob
# Hallo Eve

While-loop: blijft herhalen zolang een voorwaarde True is.

energie = 5

while energie > 0:
    print("Ik werk nog...")
    energie -= 1

# De lus stopt wanneer energie 0 wordt

Geneste lussen

Een lus in een lus: de binnenste lus wordt volledig doorlopen bij elke stap van de buitenste.

for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()

# 1 2 3
# 2 4 6
# 3 6 9

Opgelet: oneindige lussen

Een while-lus stopt enkel als de voorwaarde ooit False wordt. Vergeet je de variabele in de voorwaarde aan te passen, dan loopt je programma eindeloos verder.

teller = 0

while teller < 3:
    print(teller)
    # FOUT: teller verandert nooit, dus teller < 3 blijft altijd True!
    # Oplossing: voeg hier teller += 1 toe.

Tip: controleer bij elke while-lus: (1) wat verandert er in de lus, en (2) zorgt dat ervoor dat de voorwaarde ooit False wordt? Zit je programma toch vast? Stop het met de stopknop van je editor of met Ctrl + C.

10. Functies

Wanneer je een stuk code wil groeperen, kan je een functie gebruiken. Een functie heeft soms een input die aan het begin wordt meegegeven. De code in een functie kan je oproepen wanneer of hoe vaak je wil. Pas wanneer je de functie oproept bepaal je de inputwaarden.

Hieronder zie je twee functies. return geeft een waarde terug zodat je die verder kan gebruiken, maar toont deze niet op het scherm. print() geeft geen waarde terug die je kan herbruiken, maar toont ze meteen op het scherm.

def bereken_btw(bedrag):
    totaal = bedrag * 1.21
    return totaal

factuur = bereken_btw(100)
print(factuur)

# Variabele 'factuur' bevat nu de waarde 121.0
# Op het scherm verschijnt: 121.0

def toon_btw(bedrag):
    totaal = bedrag * 1.21
    print(totaal)

resultaat = toon_btw(100)


# Op het scherm verschijnt: 121.0
# Variabele 'resultaat' bevat None (niets) want de functie gaf niets terug.

Scope: waar bestaat een variabele?

Een variabele die je in een functie aanmaakt is lokaal: ze bestaat enkel tijdens die functie. Variabelen buiten functies zijn globaal.

x = 10

def test():
    x = 5        # een nieuwe, lokale x
    totaal = 99
    print(x)

test()          # 5
print(x)        # 10  (de globale x is niet veranderd)
# print(totaal) zou een NameError geven: totaal bestaat enkel in test()

Tip: geef gegevens mee via parameters en haal resultaten eruit via return, in plaats van globale variabelen te gebruiken.

11. Recursie

Wanneer een functie zichzelf opnieuw aanroept noemen we dit recursie.

Er moet altijd een stopconditie (base case) zijn. Anders roept hij zichzelf een onbepaald aantal keer op.

def som_tot_nul(n):
    if n == 0:
        return 0
    else:
        return n + som_tot_nul(n - 1)
som_tot_nul(3)

# Wat gebeurt er bij som_tot_nul(3)?

som_tot_nul(3)
= 3 + som_tot_nul(2)
= 3 + (2 + som_tot_nul(1))
= 3 + (2 + (1 + som_tot_nul(0)))
= 3 + (2 + (1 + 0))
= 6

12. Modules en nette code

Modules importeren

Python bevat extra functies die je met import binnenhaalt. Dit zijn modules.

import math
print(math.sqrt(25))   # 5.0
print(math.pi)         # 3.141592653589793

import random
print(random.randint(1, 6))   # willekeurig getal van 1 t/m 6
kleuren = ["rood", "blauw"]
print(random.choice(kleuren))  # willekeurig element
random.shuffle(kleuren)        # husselt de lijst zelf

from math import sqrt   # enkel sqrt, zonder "math." ervoor
print(sqrt(16))       # 4.0

Commentaar

# Dit is commentaar: Python negeert het.
# Leg uit WAAROM je iets doet, niet wat er al duidelijk staat.
prijs = 19.95   # prijs per stuk in euro

Nette code

  • Kies duidelijke namen in kleine letters, met _ tussen woorden: aantal_leerlingen, niet a of x1.
  • Spring in met 4 spaties na elke :. Python gebruikt de inspringing om blokken te herkennen.
  • Zet alle import-regels bovenaan je programma.
  • Verdeel je programma in kleine functies die elk één taak doen.

13. Data inlezen en wegschrijven, TO BE REVISED

Programma's krijgen hun gegevens vaak van buiten het programma: van de gebruiker, uit een tekstbestand of uit een export van een ander programma zoals Excel. Dan staat de data in een bestand dat Python moet openen, lezen en sluiten.

Data van de gebruiker: input()

naam = input("Wat is je naam? ")
leeftijd = int(input("Hoe oud ben je? "))  # input() geeft ALTIJD een string: zet om met int()

Een tekstbestand lezen

with open("notities.txt", "r", encoding="utf-8") as f:
    inhoud = f.read()          # alles in één string

with open("notities.txt", "r", encoding="utf-8") as f:
    for regel in f:           # regel per regel
        print(regel.strip())   # strip() verwijdert de \n op het einde

# 'with' sluit het bestand automatisch, ook bij een fout.
# Het bestand moet in dezelfde map staan als je programma,
# anders krijg je een FileNotFoundError.

Een bestand schrijven

with open("resultaat.txt", "w", encoding="utf-8") as f:
    f.write("Hallo wereld\n")

# "r" = lezen    "w" = schrijven (overschrijft het bestand!)    "a" = toevoegen achteraan

Gestructureerde data: CSV-bestanden

Een CSV-bestand (bv. een export uit Excel) is gewoon tekst waarin de waarden gescheiden zijn door een teken. In Belgische versies van Excel is dat vaak een ;. Alles wat je inleest is tekst, dus zet getallen zelf om met int() of float().

# Inhoud van scores.csv:
# naam;punten
# Alice;15
# Bob;18

totaal = 0
with open("scores.csv", "r", encoding="utf-8") as f:
    f.readline()                          # eerste regel (de titels) overslaan
    for regel in f:
        naam, punten = regel.strip().split(";")   # "Alice;15" wordt ['Alice', '15']
        totaal += int(punten)
        print(naam, punten)

print("Totaal:", totaal)   # Totaal: 33

Met de ingebouwde module csv doe je hetzelfde zonder zelf te splitsen. Elke rij wordt dan een dictionary, met de titels als sleutels:

import csv

with open("scores.csv", "r", encoding="utf-8") as f:
    for rij in csv.DictReader(f, delimiter=";"):
        print(rij["naam"], int(rij["punten"]))

Een ander formaat: JSON

JSON slaat dictionaries en lijsten op in een tekstbestand. Anders dan bij CSV blijven getallen en lijsten hun type behouden.

import json

leerling = {"naam": "Alice", "punten": [15, 18]}

with open("leerling.json", "w", encoding="utf-8") as f:
    json.dump(leerling, f)        # dictionary wordt naar het bestand geschreven

with open("leerling.json", "r", encoding="utf-8") as f:
    data = json.load(f)           # bestand wordt weer een dictionary

print(data["punten"][0])  # 15

14. Geavanceerde technieken

List comprehension: een lijst bouwen in één regel

kwadraten = [n ** 2 for n in range(5)]
# [0, 1, 4, 9, 16]

even = [n for n in range(10) if n % 2 == 0]
# [0, 2, 4, 6, 8]

enumerate en zip

namen = ["Alice", "Bob"]
punten = [15, 18]

for i, naam in enumerate(namen):       # index + element
    print(i, naam)                         # 0 Alice, 1 Bob

for naam, punt in zip(namen, punten):     # twee lijsten tegelijk
    print(naam, punt)                      # Alice 15, Bob 18

Lambda en sorteren met een eigen regel

woorden = ["banaan", "kiwi", "appel"]

# Sorteer op lengte van het woord:
print(sorted(woorden, key=lambda w: len(w)))
# ['kiwi', 'appel', 'banaan']

Fouten opvangen met try / except

try:
    getal = int(input("Geef een getal: "))
    print(100 / getal)
except ValueError:
    print("Dat was geen getal.")
except ZeroDivisionError:
    print("Delen door nul kan niet.")

Klassen: eigen datatypes maken

Een klasse is een bouwplan. Een object is een concreet exemplaar daarvan met eigen waarden (self) en functies (methodes).

class Hond:
    def __init__(self, naam):
        self.naam = naam

    def blaf(self):
        print(self.naam, "zegt: Waf!")

rex = Hond("Rex")
rex.blaf()  # Rex zegt: Waf!

15. Hoe werkt een compiler?

Een processor begrijpt enkel machinetaal (reeksen van 0 en 1). Python, Java of C zijn leesbaar voor mensen, dus ze moeten eerst vertaald worden. Dat doet een compiler of een interpreter.

Compiler versus interpreter

Compiler (C, C++, Rust): vertaalt het volledige programma vooraf naar machinecode en maakt een uitvoerbaar bestand. Dat is snel, maar je moet eerst compileren.

Interpreter: leest de code en voert ze direct uit, stap voor stap. Dat is flexibel, maar trager.

Python is een mengvorm: de code wordt eerst gecompileerd naar bytecode (tussentaal), die daarna door de Python Virtual Machine wordt uitgevoerd.

De fasen van een compiler

  1. Lexicale analyse: de tekst wordt opgesplitst in tokens (naam, getal, operator, ...).
  2. Parsing: de tokens worden omgezet in een syntaxboom (AST). Hier ontdekt Python een SyntaxError.
  3. Semantische analyse: controle of de code zinvol is (bestaat de variabele? kloppen de types?).
  4. Optimalisatie: de code wordt korter of sneller gemaakt.
  5. Codegeneratie: de uiteindelijke machinecode of bytecode wordt geschreven.

Voorbeeld: x = 2 + 3 * 4

# Tokens:  x   =   2   +   3   *   4
#
# Syntaxboom (3 * 4 wordt eerst berekend):
#
#       =
#      / \
#     x   +
#        / \
#       2   *
#          / \
#         3   4

Je kan de bytecode van Python zelf bekijken:

import dis
dis.dis("x = 2 + 3 * 4")

# Python rekent 2 + 3 * 4 al uit tijdens het compileren (optimalisatie).
# De bytecode bevat dus ongeveer:
#   LOAD_CONST   14
#   STORE_NAME   x

Tip: een SyntaxError ontstaat tijdens het compileren (nog voor er iets wordt uitgevoerd). Een NameError of ZeroDivisionError ontstaat pas tijdens het uitvoeren.
